# 墨七火柴人无限乱斗 · Moqi Stickman Ink Brawl

「火柴人格斗」的姐妹作——*。无尽波次的火柴人围攻战，水墨风开篇，招式池全面扩充。**零美术/音频资源**，全部程序化生成，包体极小、加载即玩。

## 玩法

| 模式 | 内容 |
|------|------|
| 无限乱斗 | 无尽波次，敌人数随波叠加（第 1 波 2 个、第 2 波 4 个…上限 8 个，每 5 波 1 精英 BOSS + 2 小兵）；每个敌人头顶独立血条（金框 = 当前主敌）；人多时单个敌人削弱；波次间回血；死亡可看激励广告满血复活 |
| 武道场 | 6 款皮肤，金币购买，其中「暗影」皮肤观看广告解锁 |

场景轮换以**水墨山水**（ink：宣纸 + 淡墨远山 + 朱砂红日）开篇，随后夜幕/雨夜/竹林/暮色/工厂等轮转，每 5 波火山 Boss 战。

## 招式表（16 招）

| 输入 | 招式 | 说明 |
|------|------|------|
| 连按拳 | 直拳 → 右勾拳 → 上勾拳 | 三段终结，小浮空可追击 |
| 连按踢 | 直踢 → 扫踢 → 直踢 → … | 两段无限循环，扫踢下段破防击倒 |
| 前推 + 拳（走） | 冲拳 | 弓步突进直拳 |
| 前推 + 拳（**跑**） | **冲膝** ★ | 弓步提膝前顶，双手压肩 |
| 前推 + 踢 | 踏踢 | 大踏步侧踹 |
| **后拉 + 踢** | **后蹬踢** ★ | 转身蹬踹身后——被包抄时的破局技 |
| 空中 + 下 + 踢 | **践踏** ★ | 速降下压踩踏，落地冲击击倒 |
| 空中 + 攻击 | 飞踢 | 侧蹬 |
| 蹲 + 攻击 | 升龙拳 | 强击飞（浮空连段起手） |
| 能量满 | 奥义·烈焰连舞 | 突进六连 + 升龙终结 |

★ 为本作新增。其余战斗系统：格挡（减伤 82%）、浮空追击、击倒/起身、hit-stop、震屏、连击计数、KO 慢动作、头顶血条等全部继承。

## 操作

- **触屏**（横屏）：左半屏浮动摇杆（走/跑/跳/蹲）+ 右侧 拳/踢/防/必杀 四键
- **键盘**（浏览器预览）：`←→`/`AD` 移动 · `↑`/`W`/`空格` 跳 · `↓`/`S` 蹲 · `J` 拳 · `K` 踢 · `L`/`Shift` 防御 · `U` 必杀
  - 冲膝 = 推满方向跑起来再按 `J`；后蹬踢 = 拉后 + `K`；践踏 = 空中按 `S`+`K`

## 目录结构

```
moqi-stickman-brawl/
├── game.js               # 微信小游戏入口
├── game.json / project.config.json
├── index.html            # 浏览器预览页（仅开发用）
├── js/                   # 15 个模块（与火柴人格斗同构，见各文件头注释）
└── test/                 # Node 冒烟 + headless 浏览器测试
    ├── smoke.js          # 全流程：乱斗对打→结算→翻倍→复活→导航
    ├── wave-test.js      # 多波次推进 + 敌人数/血量下限断言
    └── *.html            # headless 视觉/输入回归页
```

## 快速开始

- **浏览器**：直接打开 `index.html`（广告为模拟行为，直接发放奖励）
- **微信开发者工具**：导入 `moqi-stickman-brawl/` 目录，AppID 填自己的测试号


## 数值调参

所有平衡数值集中在 `js/config.js`（攻击表 / 波次成长 / 皮肤价格）。

## 测试

```bash
node test/smoke.js     # 全流程冒烟（含新招 [2.8]、乱斗对打 [3]）
node test/wave-test.js # 多波次推进验证
```
